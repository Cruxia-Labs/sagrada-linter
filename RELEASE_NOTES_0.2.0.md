# sagrada-linter 0.2.0 — the reading, the gate, and forgetting with proof

*Publishes on the founder's hold-lift word, strictly before season open
(the workflow pin and every install doc reference 0.2.0). 0.1.x remains
the scanner; 0.2.0 is the instrument.*

## New

- **`read`** — the staged first reading of a repo's belief history: which
  rules were born, which were deliberately killed, which are active again
  today, each with its commit pair and days walking. A clean repo gets a
  baseline, not a shrug. `--html` drops a self-contained, script-free
  epitaphs card; `--receipt` signs the reading; `--strict` for CI.
- **`--sessions`** — opt in to checking your own local agent transcripts:
  a rule you asked to bring back is a **restoration, not a zombie** — the
  tool acquits with the quote and timestamp. Local only, never silent,
  nothing leaves the machine.
- **`restore FILE LINE --reason`** — declare a resurrection: the marker in
  the file, the reason in a dated ledger; the reading then shows RESTORED
  WITH INTENT and CI passes.
- **`guard`** — the retention half: locks every dead rule into
  `.crux/lock.json`; an undeclared return fails `--check` with its kill
  history and the sanctioned command attached. `--shadow` reports without
  blocking; `--workflow` installs a shadow-mode GitHub Action (pinned).
- **`forget FILE LINE --reason`** — retract with proof: the edit, the
  residue review-queue (depth-1 textual, stated), the dated tombstone, and
  a signed receipt under the doctrine that any return of the term is a
  conflict. Forgetting becomes a maintained state: `guard` holds the grave.

## Unchanged, load-bearing

- `scan-history`, `vitals`, `check-action`, `verify` — same flags, same
  frozen VITALS method, same receipt rail (two independent verifiers +
  golden vectors).
- Verdicts are arithmetic on your git history. No model participates, no
  network is used, nothing is uploaded — same as it ever was.

## Fences (stated here first)

- Presence, never causation: "active again in the file today" is a fact
  about the record; whether any model acted on it is not claimed.
- The instrument reads structured rule lines (the measured structured
  share in the wild: 86%, N=100). Prose-only rules are out of scope.
- Receipts are self-issued (`key_tier: ephemeral`) — integrity is
  recomputation, not signature provenance.
